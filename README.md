# **Capstone\_1: EmporiUm Sales Territory Analysis (Florida)**



#### **Overview:**



This project analyzes sales performance for the Florida territory, managed by Lana Ilana, in the South region of EmporiUm. The goal is to use SQL and Excel to explore sales trends, compare performance, and provide data-driven recommendations for future sales strategies.



#### **Objectives:**



* Calculate total revenue and identify the data time period
* Analyze month-by-month revenue trends
* Compare Florida’s performance to the South region
* Evaluate transactions and average sale size by product category
* Rank store performance within Florida
* Provide a recommendation for next quarter’s sales focus



#### **Tools Used:**



* MySQL Workbench (SQL queries and data analysis)
* Microsoft Excel (PivotTables and PivotCharts)
* GitHub (project version control and repository management)
* PowerPoint (presentation)
